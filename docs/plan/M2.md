# M2 — Synthesis (`dla/rtl`, `dla/synth`)

Goal: synthesizable Verilog-2005 (subset) → gate-level netlist of Liberty cells
(IHP sg13g2 first), proven equivalent to the RTL, with area within 1.3× of
Yosys + ABC on the same library.

## Pipeline

```
rtl/*.v --lex/parse--> AST --elaborate--> flat module: params resolved, generate unrolled,
        hierarchy inlined --bit-blast--> AIG + FFs --optimize--> AIG' --map--> cells
        --FF map, ties--> dla.db.Design --> synth.v
checks:  AIG vs Design (SAT, FF boundary)   RTL vs Design (Icarus + IHP cell models, oracle)
```

The word-level step is folded into bit-blasting: every expression is evaluated
symbolically to a vector of AIG literals with Verilog width/sign rules, `always`
blocks become per-bit mux trees (if/case), so there is no separate word-level IR
until an optimisation needs one (e.g. arithmetic-aware mapping later).

## Verification

1. **Front end vs Icarus** (oracle, `tests/oracle/`): random stimulus, RTL simulated
   by Icarus and our AIG simulated cycle by cycle; outputs must match every cycle.
2. **SAT equivalence** AIG(elaborated) ≡ Design(mapped) at FF boundaries; FFs paired by
   name. Run on every synthesis (cheap for the benches) and in tests.
3. **Gate-level oracle**: Icarus with the IHP cell Verilog models simulates `synth.v`
   against the RTL with random stimulus.
4. **Area oracle**: Yosys `synth -top; dfflibmap; abc -liberty; opt_clean` with the same
   cell set; our area / Yosys area ≤ 1.3.
5. Unit tests: lexer/parser errors with line numbers, width/sign rules, every operator
   against Python reference values, SAT on random 3-SAT (vs brute force), mapper on
   single functions (every library function maps to its own cell at minimum area).

Oracle tests skip when `yosys` / `iverilog` are not installed.

## Benchmarks (`bench/`, written for this repository, MIT)

`counter8` (enable, sync clear), `gcd` (16-bit, FSM), `uart_tx`, `uart_rx`
(parameterised baud divider), `alu32` (add/sub/logic/shift/compare). Later: a small
open-source RISC-V core (SERV, ISC licence) once the front end covers it.

## Steps (each with tests, one or more commits)

1. AIG + bit-parallel sim; lexer, parser, elaboration → AIG; Icarus oracle on small
   RTL and the benches.
2. SAT + CEC.
3. Target library, cut mapper (area), FF / tie mapping, Design output, `gen.py synth`,
   gate-level checks.
4. Optimisation (balance, FRAIG), delay mode, area recovery tuning; Yosys comparison
   on all benches; README table.

## Risks

- Front-end coverage is the long tail; unsupported constructs stop with a clear error
  instead of being approximated.
- Pure Python speed: AIGs of the benches are ≤ ~20k nodes; cut enumeration is the
  hot spot (bounded cuts per node, truth tables as ints).
- Area target vs ABC (which runs `dch` + `amap`/`nf`): if the plain cut mapper is
  not within 1.3×, add choice nodes or AIG rewriting before mapping; measured, not
  guessed.
- Reset style: IHP has only active-low async reset FFs (`dfrbp*`); other styles are
  built with inverters as described above.

## Result

| Item | Status |
|---|---|
| Front end | lexer + preprocessor, parser, elaborator; feature test and all benches match Icarus cycle by cycle (`tests/oracle/test_rtl_icarus.py`) |
| AIG / SAT | strashed AIG, CDCL solver (PHP(8,7) in ~1 s), FRAIG, CEC with counterexamples |
| Optimisation | sweep, FRAIG, ISOP refactoring (8-leaf reconvergence cuts), balancing; AIG nodes −35 % (gcd), −50 % (uart_rx) |
| Mapping | priority cuts k = 6, 8 cuts/node, Boolean matching over all permutations / inversions, area flow + exact area; delay mode with required times (−6 … −15 % depth for +0.3 … +2.2 % area) |
| FFs / ties | Liberty `ff` cells; inverted storage for async set; clock inverter for the other edge; complement output (Q_N) used when it saves an inverter; tie cells per constant load |
| Verification | every netlist SAT-proven equivalent before it is written; Icarus gate-level simulation with IHP cell models: 0 mismatches on all benches |
| Area vs Yosys 0.33 + ABC | 1.01 / 1.07 / 1.06 / 1.00 / 0.94 (counter8 / gcd / uart_tx / uart_rx / alu32) — target ≤ 1.3 met |
| Run time | ≤ 5 s per bench (alu32, incl. verification); building the IHP match table 2 s once |
| Tests | 118 passed with IHP + yosys + iverilog; 78 passed / 14 skipped without `DLA_TECH` (incl. a byte-determinism check across hash seeds) |

Measurements that drove the design: ABC `map -a` on our un-restructured AIG gave 5659 µm²
logic for gcd (our mapper: 4990), with `dc2` 4487 — the gap to Yosys was AIG structure,
not mapping, so refactoring was added (gcd logic 4990 → 3635).

Open points:
- Word-level optimisations Yosys runs before ABC (`alumacc`, `share`, `fsm` recoding) are
  not implemented; gcd is the bench where this shows (1.07×).
- Memories (`reg [7:0] mem [..]`), `inout`, latches, multi-dimensional arrays, `$display`
  -free testbench constructs and SystemVerilog are rejected with clear errors.
- `--sdc` is recorded but synthesis is not timing driven yet (delay mode uses nominal
  delays); timing-driven sizing comes with STA (M3) and M7.
- A small RISC-V core (SERV) as an additional benchmark is pending front-end coverage
  (memories).
