# M1 — Timing library (Liberty)

Goal: read the PDK's Liberty (.lib) files into the design database so synthesis
(M2) can map onto real cells and STA (M3) can compute delays. The first flow runs on
the IHP `sg13g2_stdcell` library. M1b (own sequential/mux/xor cells and an
ngspice-based characterizer) is a parallel track with its own plan
(`docs/plan/M1b.md`), started after this part lands.

## Scope

| In M1 | Deferred |
|---|---|
| Generic Liberty parser (groups, simple/complex attributes, `\` continuations, comments, quoted strings) with `file:line` errors | CCS / ECSM tables, `statetable` semantics (kept raw, flagged unsupported) |
| Semantic layer: units, thresholds, operating conditions, templates, cells (area, footprint, `dont_use`, leakage), pins (direction, cap rise/fall, max cap/transition, function, clock, three_state), timing arcs (related pin, sense, type, `when`, NLDM tables), `ff` / `latch` groups | Power-aware analysis (internal power tables are parsed but unused) |
| NLDM table lookup: bilinear interpolation, linear extrapolation outside the index range, 1-D and scalar tables | Wire-load models (parsed as raw groups only; the flow uses placement-based estimates) |
| Boolean `function` parser + evaluator (`! ' * & + \| ^`, implicit AND, constants), truth tables, unateness from the function | |
| Liberty writer (generic tree) — needed by M1b `charlib` | |
| `Library` integration: `lib.add_liberty(path)`, `Library.from_tech(tech, corner)`, LEF ↔ Liberty cell join | |
| tech file: `files.liberty` (list, or `{corner: [paths]}`), documented in `TECH_FILE.md` | |

## Data structures (`dla/db/liberty.py`)

```
Group(type, args, attrs {name: value}, complex [(name, [values])], groups [Group], line)
      # generic, order preserving, round-trippable

LibertyLib
  name, time_unit (ns per lib unit), cap_unit (pF per lib unit), voltage, temperature
  thresholds {input_rise, input_fall, output_rise, output_fall, slew_lower_rise, ...}
  slew_derate, templates {name: Template(vars, index_1, index_2)}, defaults {...}
  cells {name: LibCell}

LibCell
  name, area, footprint, dont_use, is_sequential, leakage, pins {name: LibPin}
  ff: Seq(kind="ff", state=("IQ","IQN"), clocked_on, next_state, clear, preset, ...)
  latch: Seq(kind="latch", enable, data_in, ...)
  unsupported: [reasons]           # statetable, test_cell, ...

LibPin
  name, direction, capacitance, rise_cap, fall_cap, max_cap, max_transition, min_cap,
  function (Expr or None), clock, three_state (Expr), arcs [TimingArc]  # arcs to this pin

TimingArc
  related (pin), sense (positive_unate/negative_unate/non_unate), type (combinational,
  rising_edge, setup_rising, hold_rising, clear, preset, min_pulse_width, ...), when,
  tables {"cell_rise", "cell_fall", "rise_transition", "fall_transition",
          "rise_constraint", "fall_constraint": Table}

Table(index_1, index_2, values, var_1, var_2)   # internally ns / pF
  lookup(slew, load)   # variables mapped by template names, so transposed templates work
```

All times are converted to **ns** and capacitances to **pF** on read, whatever the
library declares (`time_unit : "1ps"`, `capacitive_load_unit (1, ff)` ...), so later
stages never see library units.

## Algorithms

- Tokenizer: one regex pass (identifiers/numbers, quoted strings, `{ } ( ) : ; ,`),
  `/* */` and `//` comments, `\` line continuations. Recursive group parser into
  `Group`; attribute values keep their source text (strings unquoted) and are
  typed only by the semantic layer.
- Table lookup: find the bracketing interval per axis (clamped to the outer
  interval, which gives linear extrapolation beyond the ends), bilinear formula —
  the standard NLDM treatment also used by OpenSTA.
- Function expressions: precedence `!`/`'` > XOR (`^`) > AND (`*`, `&`,
  juxtaposition) > OR (`+`, `|`), as in OpenSTA's Liberty expression grammar; evaluation over a dict of 0/1; truth tables by enumeration
  (≤ 6 inputs here); unateness per input from cofactors.

## Tests (`tests/test_liberty.py`)

Without PDK (hand-written `tests/data/tiny.lib`, gitignore exception like `tiny.lef`):
1. Parser: groups, complex attributes, continuations, comments; error with line number.
2. Units: a ps / fF library converts to ns / pF.
3. Table: exact at grid points, bilinear in between, linear extrapolation outside,
   1-D and scalar tables, template variable order (load first) handled.
4. Functions: `!(A*B)`, `A'`, implicit AND, `^`, constants; unateness.
5. Writer: parse → write → parse gives the same tree.

With `DLA_TECH` (IHP, all six corners):
6. 89 cells, every LEF core macro (except fillers/decaps without timing) has a
   Liberty cell with the same pins; pin directions agree with LEF.
7. Functions of the logic cells match their names (inv, nand2/3/4, nor2/3/4,
   and/or, xor/xnor, mux2/4, a21o, o21ai, a22oi, ...) by truth table.
8. `sg13g2_dfrbp_1`: ff with `clocked_on CLK`, `next_state D`, `clear !RESET_B`;
   setup/hold arcs on D related to CLK; rising_edge arcs CLK→Q.
9. Sanity over every combinational delay table: delay and transition
   non-decreasing in load; slow corner slower than typ slower than fast for
   the same arc at the same point.
10. Lookup at a table point equals the file value (spot checks on nand2_1).

## Risks

- Liberty files from other vendors use constructs not in IHP (bus/bundle pins,
  `statetable`, CCS). The generic parser accepts any well-formed group; the
  semantic layer records unsupported content on the cell instead of guessing, and
  synthesis/STA refuse such cells explicitly.
- No OpenSTA in this container, so lookup is checked against hand-computed values;
  the M3 oracle comparison will exercise it end to end.
- Parse time of the pure-Python reader (1.7 MB per corner): target < 2 s per file.

## Result

| Item | Status |
|---|---|
| `dla/db/liberty.py` | generic parser/writer, `LibertyLib`, NLDM `Table`, `Expr`; ~600 lines, stdlib only |
| `Library` integration | `add_liberty`, `from_tech(tech, corners)`, `timing()`, `check_join()`; tech file `files.liberty` per corner (IHP: typ / slow / fast) |
| IHP, 6 corner files | 84 cells each, 0.3–0.7 s per file; LEF ↔ Liberty join clean for every corner (internal pins such as `int_GATE` excluded) |
| Functions | every inv/buf/and/or/nand/nor/xor/xnor cell matches its name by truth table; mux2, a21oi, tie cells checked; every combinational arc's `timing_sense` equals the function's unateness, including state-dependent (`when`) arcs of mux/xor |
| Sequential | `ff` (dfrbp: CLK / D / clear !RESET_B) and `latch` (dlhq) groups; setup/hold arcs present; clock gates (`lgcp`, `slgcp`) use `statetable` → listed as unsupported |
| Table sanity | > 900 delay/transition tables: non-decreasing in load; slow > typ > fast at two operating points for every arc except three-state enable/disable (not load driven) |
| Lookup | exact at grid points, bilinear inside, linear extrapolation outside, 1-D / scalar tables, transposed templates (load first), table index overriding template index |
| Round trip | tiny.lib parse → write → parse identical, write byte-stable |
| Test suite | 65 passed with IHP (+10 Liberty tests); 35 passed / 13 skipped without `DLA_TECH` |

Notes:
- `LibPin.arc(related)` returns the unconditional arc when state-dependent ones exist;
  STA (M3) will have to choose between `when` arcs explicitly (worst case by default).
- Not validated against OpenSTA (not installed here); M3's oracle comparison covers
  the lookup end to end.
- Internal power / leakage groups are parsed into the tree but not modelled.
